# Pixora v0.3.12

本版重点修复 USB 手机图片浏览、连续打开请求和缓存问题。

## 更新内容

- 修复从资源管理器打开手机照片后只能查看首张、较大图片无法继续读取，以及上一张/下一张跳回旧本地目录的问题。设备目录按需读取当前文件，不预下载整个目录。
- 新增手机读取失败后的“重试读取”和原始副本保存。保存直接复制原始字节，保留格式和元数据；临时缓存被清理时可重新取得原文件。
- 修复手机重新连接后的目录恢复，以及恢复当前项后后续未缓存图片仍超时的问题。
- 改进窗口复用和连续打开：慢请求不会阻塞新请求接收，旧加载任务的迟到结果不会覆盖当前选择。
- 修复 EXIF 方向处理，包括镜像方向；主图与缩略图使用一致的方向变换。
- 优化内存缓存的最近使用顺序维护，避免每次命中遍历缓存；损坏的磁盘缩略图可清理并重新生成。
- 增加设备恢复、打开会话、原始副本、命名管道确认、方向及缓存回归测试。

## 验证

构建和完整 smoke tests 通过，包含 11 项命名管道确认回归及 4 张真实手机截图样本。真实设备完成两轮断线重连，修复后重试当前项及连续读取后续未缓存图片均通过。

本地界面检查覆盖 500 项小图目录、缩略图单/双列、收藏、设置持久化、自定义快捷键、裁剪、压缩和动图播放暂停；导出文件另行核验。加载重叠时序使用自动门控回归，500 项小图结果不代表真实大图目录性能。详细覆盖范围见 [验收记录](https://github.com/OmoriRay/Pixora/blob/v0.3.12/docs/VALIDATION-2026-11-05.md)。

## 使用说明

- Windows 10 x64 最低支持 22H2；同时支持 Windows 11 x64。
- 下载包需要 .NET Desktop Runtime 9 x64。
- 浏览手机图片时，请保持设备解锁、启用文件传输，并保留资源管理器中的原手机目录。断线后若 Windows 关闭了目录窗口，请重新打开同一目录，再点击“重试读取”。
- 设备视图为只读。编辑、压缩或收藏前，请先保存原始副本到电脑。
- 本版使用新标签和新下载包，不替换旧版本附件。
