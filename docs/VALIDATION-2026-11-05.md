## 本轮测试发现并修复

- 可见图片的临时原文件可能已不存在，原始副本保存曾因此显示“文件夹不存在”。现在保存前重新校验来源；缓存确实缺失时，向当前手机会话重取原始字节，随后保存，并防止重取期间切换会话写入过时结果。
- 实机重取暴露出 MTP 目录的 `Self.Path` 不能保证被 `Shell.NameSpace(string)` 接受。重连现在优先重新取得身份一致的已打开资源管理器目录，再校验原文件身份和大小；不扫描设备树。
- 重连恢复当前项后，后续未缓存图片不能继续使用断线前的文件项对象。新传输现在都重新取得当前文件项，完整缓存仍直接复用。
- Windows 上目标文件被占用时，原始副本测试可能收到 `UnauthorizedAccessException`；用例现在同时接受相应的 I/O 拒绝，并继续检查原目标未被修改。
- 设置窗口测试补齐 WPF 同步上下文和关闭清理，并阻止合成测试设置覆盖用户偏好。

验收结束后已通过界面关闭全部测试程序，恢复本次测试前的设置、快捷键、收藏、批量压缩配置及对应 `.bak`，共 8 个文件；逐个 SHA-256 比对均与快照一致。
